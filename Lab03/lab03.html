This website outlines the challenges and differences I have encountered while doing my lab assignment for this week.

Comparison

For Part A, I implemented media queries along with CSS Grid and Flexbox layouts to ensure the website is responsive across various device screen sizes.
For Part B, I utilized Bootstrap's flexbox container, which automatically adjusts the layout to be responsive across all devices.

Challanges

While working on both parts, I encountered the challenge of navigating through various CSS properties to achieve the desired look for the website.
Compared to using plain HTML and CSS, applying the Bootstrap framework was a bit more challenging, as the HTML document doesn't seem to support an external stylesheet once the Bootstrap CDN is applied.
Therefore, in my opinion, working with just HTML and CSS was easier compared to using the Bootstrap framework.
